02 / CORE CAPABILITIES

What FocalPoint Does

Persistent Memory

6-layer memory architecture — from company constitution to temporary context. Agents never forget critical decisions.

Attention Management

Heartbeat system detects stale tasks, blocked items, and at-risk deadlines. Surfaces what matters now.

Context Assembly

4-layer context bundling — dashboard, alerts, neighborhood, and deep detail. Right context, right time.

Task Orchestration

Hierarchical work items with dependencies, risk detection, and automatic escalation. Work flows, not stalls.

Knowledge System

Structured knowledge docs with inheritance. Parent context flows down to child tasks automatically.

Review Protocol

Built-in review gates with parallel approval. Quality checks before execution, not after.
